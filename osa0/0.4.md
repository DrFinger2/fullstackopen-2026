```mermaid
sequenceDiagram
    participant browser
    participant server

    Note right of browser: 1. User enters note and clicks save
    browser->>server: POST https://studies.cs.helsinki.fi/exampleapp/new_note
    activate server
    Note left of server: 2. Server stores the new note.
    server-->>browser: HTTP 302 Found (Location: /exampleapp/notes)
    deactivate server
    Note left of server: 3. Server returns a redirect 

    Note right of browser: 4. Browser follows the redirect.
    browser->>server: GET https://studies.cs.helsinki.fi/exampleapp/notes
    activate server
    server-->>browser: 200 OK - HTML (notes.html)
    deactivate server
    Note left of server: 5. Server returns the HTML file.

    Note right of browser: 6. Browser starts parsing the HTML document.
    Note right of browser: 7. Browser encounters <Link> element.
    Note right of browser: 8. Browser requests the CSS file in it.
    browser->>server: GET https://studies.cs.helsinki.fi/exampleapp/main.css
    activate server
    server-->>browser: 200 OK - CSS (main.css)
    deactivate server
    Note left of server: 9. Server returns the CSS file.
    Note right of browser: 10. Browser encounters <Script> element.
    Note right of browser: 11. Browser requests the Javascript file in it.
    browser->>server: GET https://studies.cs.helsinki.fi/exampleapp/main.js
    activate server
    server-->>browser: 200 OK - Javascript (main.js)
    deactivate server
    Note left of server: 12. Server returns the Javascript file.

    Note right of browser: 13. Browser executes the Javascript file.
    Note right of browser: 14. Javascript requests the notes as JSON
    browser->>server: GET https://studies.cs.helsinki.fi/exampleapp/data.json
    activate server
    server-->>browser: 200 OK - JSON (data.json)
    deactivate server
    Note left of server: 15. Server returns the notes as JSON // .open("GET", "/exampleapp/data.json"); .send();
    Note right of browser: 16. Javascript parses the JSON and updates the DOM (xhttp.onreadystatechange).
```
