sequenceDiagram
    participant browser

    activate server
    server-->>browser: HTTP 302 Found (Location: /exampleapp/notes)

    .
    browser->>server: GET https://studies.cs.helsinki.fi/exampleapp/notes
    activate server
    Note right of browser: 3. Browser follows the redirect and reloads the page
    server-->>browser: 200 OK - Returns the html for the notes page
    deactivate server

    Note right of browser: 4. While parsing the Head section, the browser requests the CSS file.
    browser->>server: GET https://studies.cs.helsinki.fi/exampleapp/main.css
    activate server
    server-->>browser: 200 OK - Returns main.css (stylesheet for the website)
    deactivate server
    
    Note right of browser: 5. While parsing the Script section, the browser requests the JavaScript file.
    browser->>server: GET https://studies.cs.helsinki.fi/exampleapp/main.js
    activate server
    server-->>browser: 200 OK - Returns the JavaScript file

     Note right of browser: 6. Browser executes the JavaScript file
     browser->>server: GET https://studies.cs.helsinki.fi/exampleapp/data.json
     Note right of browser: 7. JavaScript requests the notes as JSON
     server-->>browser: 200 OK - Returns the notes as JSON
     Note right of browser: 8. Browser renders the updated list of notes
